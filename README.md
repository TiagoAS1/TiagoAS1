## 🚀 Sobre mim

Sou um desenvolvedor apaixonado por tecnologia e integração de sistemas, com experiência sólida em desenvolvimento web e especialização na plataforma ServiceNow. - **Plataforma ServiceNow**: Desenvolvimento de aplicações, integrações REST e automação de workflows
- **Desenvolvimento Web**: Aplicações full-stack com foco em JavaScript/TypeScript
- **Integração de Sistemas**: APIs REST, serviços web e soluções de middleware
- **Banco de Dados**: Design, otimização e gestão de bases de dados relacionais e NoSQL
